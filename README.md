# CookieShop 蛋糕商城项目
tdm做出了一写修改代码

## 项目介绍
CookieShop 是一个基于Java Web技术开发的在线蛋糕商城系统，采用JSP + Servlet架构实现，包含用户注册登录、商品浏览、订单管理、购物车等完整电商功能，是一个初次学习Java Web的大学生开发的实战项目。

## 项目用途
本项目用于模拟真实的线上蛋糕销售场景，为用户提供便捷的蛋糕选购、下单服务，同时支持商家管理商品与订单。项目完整覆盖了 Java Web 开发的核心知识点，可用于课程学习、技术练手，帮助开发者掌握前后端交互、数据库设计、电商业务逻辑实现等技能。

## 使用方法
1.  导入项目源码到 IntelliJ IDEA 等开发工具，配置 Tomcat 服务器与 MySQL 数据库，执行 `cookieshop.sql` 脚本初始化数据库。
2.  启动 Tomcat 服务器，访问项目地址，即可进入商城首页，进行用户注册、商品浏览、下单等操作。
